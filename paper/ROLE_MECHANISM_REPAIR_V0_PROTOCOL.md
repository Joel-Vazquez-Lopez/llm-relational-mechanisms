# ROLE-MECHANISM-REPAIR-v0 — prospective selected-cohort pilot

## Scope and immutable history

The four independently trained roles_8 seeds 27103, 27107, 27109 and 27114 have zero restricted strict four-query correctness in both rich held-out populations and both voices at 51,200 updates. This is a fixed, outcome-selected cohort, not a random population sample. Replication v0 remains negative; discovery v1 remains exploratory. No source model/report is overwritten. This is a prospective intervention comparison on known failures, not an independent replication or an architecture-general efficacy claim.

## Arms and training

Seven arms per seed: frozen, full_ce, random_ce, target_ce, full_weighted, random_weighted, target_weighted. All active arms start from identical checkpoint weights and fresh AdamW (lr .002, wd .01); no imported momentum. Standard CE is full-vocabulary cross entropy, exactly the parent objective. Weighted loss is event NLL + 4 * conditional-role NLL, using correct answer and the other participant in the same event, with event probability computed over the full vocabulary. The factorisation is exact at weight 1; weight 4 is fixed a priori, not tuned. This changes loss scaling and gradient magnitude as well as weighting; no claim of gradient-scale-controlled superiority. No new examples or label leakage: use the deterministic extension of original roles_8 training schedule, eight quartets, both voices, four queries each, same examples across active arms. Audit prefix against replication report and hash the extended stream. No early stopping. 6400 additional updates per active arm; checkpoints at 0, 400, 800, 1600, 3200, 6400. Frozen control has no updates. All active arms have equal update/example counts, not necessarily equal wall-clock/FLOP counts.

## Component selection and masks

Target is the expanded role component set previously selected in discovery v1 at 51,200, before repair outcomes are observed. In collapsed models this is a candidate target, not a demonstrated missing role circuit; the causal search may have selected weak or irrelevant components. A head means its Q/K/V rows (weights and biases) and its output-projection columns, excluding shared output bias. An MLP means all of its linear weights and biases. Mask gradients and restore frozen entries after AdamW to eliminate weight decay leakage. Fully frozen parameters are excluded from the optimizer. At every checkpoint verify frozen entries exactly unchanged and count trainable scalars. Random control is one deterministic draw per seed among sets with identical numbers of heads and MLPs and minimum overlap with target. Overlap may be unavoidable; record it. Parameter counts are exactly matched but layers are not matched, and one random draw per seed does not exhaust random baselines. Random and targeted masks are identical across the two loss conditions within their respective arm pairs.

## Outcomes and analysis

Primary: paired difference target_ce minus random_ce in mean restricted strict four-query correctness (C_query), averaging the two rich held-out populations and two voices equally within each seed, at 6400 extra updates. Report all four differences, mean and positive count. No significance claim with this small selected cohort. Secondary fixed contrasts: full_weighted minus full_ce, target_weighted minus target_ce, target_weighted minus random_weighted, target_weighted minus full_weighted, full_ce minus frozen, random_weighted minus random_ce. Report trajectories, full-vocabulary joint/individual accuracy, restricted individual accuracy, full-vocabulary event mass, restricted event accuracy, correct conditional role probability, role accuracy (strict logit comparison), event/role NLL and collapse of both within-event restricted prediction pairs. Role metrics are meaningful independently of event mass; inspect both before claiming repair. The pair-collapse metric counts equal predictions within each event's query pair, including wrong-event predictions. All arms evaluated on both original rich benchmark populations/voices. Reused evaluation benchmarks are not independent language or entity inventories. No evaluation example used for gradient updates. Baseline native scores must match archived replication and all arms must agree at start; frozen control must remain identical. Endpoints also use the existing replication single-head discovery/evaluation procedure, with disjoint-name and cross-voice causal transfer; this is a secondary diagnostic, not proof of absence of a distributed mechanism. No model selection or threshold changes based on repair outcomes. No claim of repair unless role and joint competence improve while event competence is retained.

## Provenance and execution

Freeze manifest, script, protocol and launcher before training. Hash input checkpoints, discovery reports, prior reports and dependencies. Keep per-arm model and optimizer checkpoints locally; report digests and schedule hashes. Resume from last contiguous sealed pair of weight/report files, retaining optimizer/RNG. A partial checkpoint stops execution for inspection; never overwrite. All 168 reports required for summary. No automatic push or deletion. CPU smoke checks CE factorisation, mask matching, zero drift under AdamW, resume equivalence and metrics. Real MPS and full dataset integration remain local checks.
