# ROLE-MECHANISM-DISCOVERY-v1

Status: exploratory follow-up, not a new confirmatory replication. Freeze this protocol, source, launcher and study manifest before any new inference. ROLE-MECHANISM-REPLICATION-v0 remains unchanged, including its failed primary criterion. No training or changes to weights. New seeds are not independent of the already examined replication study.

## Questions
Does an expanded fixed-donor readout intervention search capture relational control more effectively than the v0 individual-head pair? Do the two original successful recovery models serve as positive controls for the discovery procedure? Do source-dependent and transferable patterns persist after accounting for distributed components?

## Inputs and sampling
All 64 checkpoints of seeds 27101–27116 and the four frozen milestones, plus final roles_8 checkpoints for original positive controls 16101 and 16127. Manifest binds the bytes of checkpoint and report files, relevant source files, parent protocol digests, and the unchanged negative replication summary. Reproduce the parent fixture construction. Select 64 source indices from unseen_roles_rich (discovery) and 128 from unseen_quartets_rich (evaluation) with fixed Random seeds, excluding earlier causal-study sample indices and the v0 replication samples. Both voices, four queries per source. Discovery and evaluation use distinct original quartet populations. Synthetic evaluation recipients use known, disjoint name sets chosen deterministically by the existing localisation method; their substituted quartets can overlap other lexical combinations in training, and names are not new vocabulary. No test rows used for selecting components. New sample indices are not an entirely independent linguistic corpus. The existing native behavioural outcomes are reused from frozen checkpoint reports.

## Intervention search
At the answer readout, use clean within-model donor activations for the same input with semantic query bit flipped: role bit 1, event bit 2, both bit 3. Head activations are projected contributions; replace with an additive difference from the current forward's head contribution. MLP output is replaced directly. Multiple same-layer head contributions are simultaneous; later layers recompute with prior patches but selected outputs are clamped to clean donor values. No cross-model activation patching. Every axis tests all 15 singleton components (12 heads, 3 MLP outputs) and all 105 unordered pairs (including 66 head-head pairs). Expand the top two ranked pairs per axis with every available third component. Rank by minimum strict full-vocabulary four-query correctness across voices, then mean target probability, then smaller size, then lexicographic tie-break. Keep top five sets plus best singleton per axis; evaluate every disjoint role/event pair in the resulting shortlist plus a deterministic disjoint singleton fallback on discovery data for bits 1, 2, 3. Choose maximum worst voice-and-axis strict joint correctness, then mean target probability, then smaller total size, then lexicographic order. Residual swaps at each layer are separately measured diagnostic ceilings; they are excluded from component search because they replace cumulative upstream information. Search is bounded and not proof of globally minimal or sufficient natural circuits. An intervention that changes the predicted answer establishes causal control under that intervention, not a direct causal edge or natural algorithm by itself.

## Evaluation
Once chosen, apply the expanded sets and the original frozen individual-head pair on exactly the same new evaluation samples. Test clean recipient baseline, within-source role/event/joint switches, disjoint donor transfer, and opposite-voice disjoint donor transfer, including both-component same-query patch. Preserve separate voice-level rows; use full vocabulary, donor/recipient union, restricted recipient accuracy, target probability, and strict full-vocabulary joint correctness. Verify head reconstruction, native logits, self-patching, final residual donor-logit reproduction, and finite logits. Record complete discovery scores and selections. Use v0 classification thresholds unchanged for descriptive comparisons. A newly passing category does not change the original failed replication decision. Do not selectively rerun or tune thresholds based on test results. Compare original and expanded sets on identical samples. Positive controls: evaluate known head pairs and the automatically selected sets in both original successful models; report failure to recover either signature as a limitation, not grounds to silently alter the search.

## Reporting
Report all 16 seeds, all four checkpoints, and both controls, irrespective of success. Summaries show method-specific category counts, selected components, voice-averaged metrics and underlying voice-level rows. Independent statistical unit is seed, not query. No claim of confirmed prevalence or improved learning from this study. Any new confirmatory claim requires new independent models or a prospective experiment. Original replication result is preserved verbatim.
