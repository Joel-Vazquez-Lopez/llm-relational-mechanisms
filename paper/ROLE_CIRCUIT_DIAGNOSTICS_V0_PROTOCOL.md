# ROLE-CIRCUIT-DIAGNOSTICS-v0

Exploratory discovery, not prospective confirmation. No model training. All four recovery seeds, four arms and four checkpoints; all seven original populations and both voices. Existing TRAIN-derived evaluation fixtures only; no protected populations. No changes to parent studies. Source checkpoint/report hashes and code/protocol hashes frozen before inference.

Hypothesis: persistent collapse may reflect correct event identification without role differentiation. Alternatives include wrong-event selection, reversal, vocabulary leakage and query-insensitive output. Full vocabulary log-softmax is primary; candidate-normalized event mass is secondary. For correct entity c and same-event partner p, event mass is P(c)+P(p), conditional role probability is P(c)/(P(c)+P(p)). Cross entropy decomposes exactly into event NLL plus conditional role NLL. Conditional role accuracy compares the two logits with half credit for ties. Report signed and absolute margins, vocabulary leakage, full and candidate JS divergences for role swaps and event swaps within the same source, prediction agreement and signed role-switch contrast. JS uses natural logs. These are output diagnostics, not proof of internal mechanisms. Preserve separate voices and populations, and equal-voice descriptive summaries by seed. Arm-specific seen populations differ; common unseen populations permit matched comparisons. No pooled-query inference or confirmatory tests.

Native candidate accuracy, strict four-query accuracy, full-vocabulary accuracy and all pair taxonomy rates must reproduce archived reports within absolute 0.001 per arm/population/voice before sealing. Use original MPS backend by default. Fail closed on missing checkpoints, protocol drift or mismatch. Synthetic smoke test checks analytical ambiguity case. No partial aggregation. Existing reports never overwritten. The four seeds were selected post hoc and optimizer reset confounds recovery; no general causal claims. Subsequent activation/probe and intervention studies require separate protocols and independent validation.
