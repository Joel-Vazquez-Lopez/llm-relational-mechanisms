# ROLE-BINDING-LOCALISATION-v0

Exploratory frozen follow-up to ROLE-BINDING-CAUSAL-VALIDATION-v0. No new training. The preceding selected-seed study identified two successful eight-role models with identical native performance but divergent cross-source event-head transfer. This study tests localisation and transfer across disjoint sets of known names, not novel vocabulary or independent model replication.

## Design

All four existing recovery seeds (16101, 16127, 16143, 16167), all four saved steps (6400, 12800, 25600, 51200), eight-role arm only. Use the previously fixed candidate and comparison heads, not newly selected heads. Collapsed model role-head coordinates are matched hypotheses. Sample 64 withheld rich source indices from the same underlying held-out quartet population, excluding the three previous intervention samples across both voices, seed 20261129. Evaluate both voices separately. Two deterministic source transformations: mixed permutation (1,2,3,0) and a disjoint known-name quartet selected by deterministic search of held-out source labels, without model outputs. Replace every occurrence of each source name, including modifiers, and audit that replacements occur before the separator. Recompute labels and candidate sets. The disjoint transformation is a constructed counterfactual and may reuse previously encountered names or name combinations; report its native baseline before interpreting transfer. No claim about unseen vocabulary.

## Intervention families

- For role (bit 1), event-same (bit 0), event-flip (bit 2), and matched event control (bit 2), compare clean recipient counterfactual head output, original-source donor head output, and opposite-voice original-source donor head output. Patch at recipient readout only, using fixed absolute projected head contributions with downstream recomputation.
- To isolate source-dependent content rather than query-switch effects, construct hybrid heads using clean recipient *counterfactual-query* Q/K/V as reference and original-source *same counterfactual-query* Q/K/V as donor. Insert hybrid projected contribution into the original recipient query. Swap Q alone or QKV at all visible positions; independently swap K, V, KV within name tokens, other source tokens, separator, event-query token, role-query token, other query tokens, readout, all non-name tokens, and all visible positions. The seven disjoint base groups partition visible positions. Group localisation is at a single head's readout, not a direct path attribution. A source-dependent effect at a query token indicates contextualised source information there, not necessarily a direct source-to-token edge.
- For event-same and event-flip candidate heads, sweep single positions at offsets -12 through +12 relative to separator, patching K/V. Report fraction of examples for which offset is visible; empty masks are null patches relative to recipient counterfactual head, not missing observations. Positions outside the sweep are covered by group interventions. Compare groups before interpreting individual offsets; no posthoc confirmatory claims.
- All 15 nonempty subsets of L1 heads: patch source-name V or KV from original donor at unchanged query into recipient. This tests whether the L1 source-name effect in seed 16101 is distributed or concentrated; subsets are exhaustive, not selected based on outcomes. It is not a network sufficiency test.

## Metrics and interpretation

Use full-vocabulary argmax, union of donor and recipient candidate names, recipient-restricted argmax, target full-vocabulary probabilities, and strict four-query union correctness for recipient and donor. Both target identities differ on every row. For disjoint inventories, donor-copying cannot be evaluated using recipient-only restricted accuracy. For mixed inventories, donor/recipient candidate sets coincide. All comparisons are paired within sampled sources; conditions and voices are not independent model replications. Report both source types and voices separately, with equal-voice compact summaries. Source groups and head subsets are exploratory; no claims of statistical significance from repeated interventions. Compare recipient-head reference to donor-head patch, then determine which group hybrids reproduce donor selection. Compare source-dependent event-head transfer with role-head transfer and matched event control. A negative or low-native-baseline result is informative but does not establish absence of an abstract representation.

Primary descriptive predictions (not confirmatory): in seed 16127, source dependence may be carried by contextualised event-query token K/V; in seed 16101, name-token value retrieval may require a subset of L1 heads. If disjoint-name baseline fails, report this and do not interpret failed transfer as evidence against abstraction. Controls: clean counterfactual recipient head, original donor head, cross-voice donor, event-control head, empty position masks, Q-only and K/V reconstruction. Numerical validation includes native forward agreement, original full native score check against parent reports, self-patching, full donor QKV reconstruction and head reconstruction. No direct circuit-edge, natural-language, or independent-replication claims. Freeze source/protocol/manifest before inference; checkpoint outputs sealed once; summary derived idempotently.
