# Swedish stimuli (SV 0.1.0) — check sheet for a native speaker

Please mark anything that sounds unnatural, wrong or ambiguous. For each sentence: is it grammatical, natural, and is it clear who did what to whom? For each question: is it clear which person it asks about?

| agent | Av vem blev någon berömd? | | |
