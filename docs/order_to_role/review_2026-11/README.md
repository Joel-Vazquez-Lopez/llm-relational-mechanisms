## 1. Research question and design

When an LLM answers "who did what to whom?", does it track **linear order** (first vs second
name), **grammatical function** (subject vs object) or **thematic role** (agent vs patient),
and where across layers is the answer decided?

Constructions pull the three apart (Leon = agent):

| Construction | Example | First | Subject | Agent |
|---|---|---|---|---|
| active | Leon praised Mira. | Leon | Leon | Leon |
| passive | Mira was praised by Leon. | Mira | Mira | Leon |
| object cleft | It was Mira that Leon praised. | Mira | Leon | Leon |
| by-cleft | It was by Leon that Mira was praised. | Leon | Mira | Leon |

Across these four the three labels are exactly uncorrelated. Names are reversible (24 names,
16 verbs, no plausibility cue). Questions never name a participant ("Who praised someone?").
Prompt: `Sentence: {s}\nQuestion: {q}\nAnswer:`, chat template for Instruct models. Families
(unordered name pairs) are split 15% dev / four test sets.

Generator: `src/relational_lab/experiments/order_role_stimuli.py` (v1.3.0). Stranded-preposition
generator: `src/relational_lab/experiments/stranded_p_stimuli.py` (SP 1.1.0).

## 2. Claims, status and evidence

Status: **valid** (supported on dev), **dropped** (falsified or an artefact), **open**.

### C1. Forced-choice scoring misrepresents chat models (valid; methods result)
Forced choice compares log-probabilities of the two names as the first answer token. Without an
instruction, Instruct models usually restate the sentence ("In the sentence 'Lisa followed
Laura,' the person who was followed is Laura."), so forced choice scores which name *starts*
the reply, usually the sentence's first name. This produced an apparent human-like
subject/object asymmetry in Qwen2.5 and OLMo-2 Instruct models that free generation does not
show.

- Figure `f1_forced_choice_vs_generation.png`, table `t1`. Forced choice on all four main
  constructions (2624 dev items) vs greedy generation with "Reply with one name only." (256
  balanced items; 16 per construction × role × question voice). **Different item samples.**
- Qwen2.5-14B-I 0.71 → 0.96, Qwen2.5-7B-I 0.64 → 0.74, OLMo-2-32B 0.78 → 0.89,
  Glimmer 0.74 → 0.80, Mistral-3.2 0.84 → 0.88. **OLMo-2-13B goes the other way, 0.88 → 0.81**:
  the artefact does not inflate errors uniformly.
- The same restatement artefact also hit Gemma (C3): forced choice counted correct
  full-sentence answers as errors because they start with the patient's name.
- Dropped as a consequence: "object wh-questions make models answer with the subject"; the
  cloze-vs-question contrast as evidence of retrieval failure (it is predicted by the artefact).

### C2. "Who was someone V-ed by?" reverses roles in two strong models (valid)
Same five words as the patient question "Who was V-ed by someone?". 164 dev events per
construction. Figure `f2_stranded_by_question.png`, table `t2`.

| | active | object cleft | by-cleft | passive |
|---|---|---|---|---|
| Gemma 4 31B-it, forced choice | 0.08 | 0.10 | 0.38 | 0.85 |
| Gemma, generated, name only | 0.63 | 0.41 | 0.88 | 0.93 |
| Gemma, generated, free (sentence answers counted) | 0.54 | 0.37 | 0.53 | 0.91 |
| Qwen3.8-27B, forced choice | 0.31 | 0.19 | 0.71 | 0.72 |
| Qwen3.8, generated, name only | 0.32 | 0.13 | 0.98 | 0.75 |

Patient permutation, name only: Gemma 1.00, Qwen3.8 0.98. Errors always name the person
"someone" stands for (the patient). Accuracy depends on the sentence: high when the sentence
itself is passive. Gemma's free answers without instruction: bare-name answers 0.16 on actives
(15/91) and 0.13 on object clefts (16/120); full-sentence answers 149/149 correct.

### C3. Within-item dissociation: the same items are answered correctly as full sentences (valid; core)
Same 656 items, "Answer with a full sentence." vs "Reply with one name only.". Figure
`f3_within_item_formats.png`, table `t3`. Active + object-cleft sentences only (no "by" in the
sentence, so a correct sentence answer is a rewrite, e.g. "Frank was watched by Daniel.", not a
copy). Passive sentences are excluded: sentence answers there are verbatim copies.

- Gemma: sentence right on 328/328, including all 156 items whose bare-name answer was wrong.
- Qwen3.8: 215 items name-wrong/sentence-right vs 40 name-right/sentence-wrong (34 both right,
  39 both wrong).
- Interpretation: the models represent the event correctly and parse the question frame; the
  failure is in selecting which argument the bare answer names.
- Cross-family hint (not within-item): in free answers without instruction, full-sentence
  answers are 0.97–1.00 correct in Qwen2.5-7B/14B-I, OLMo-2-13B/32B, Glimmer.

### C4. Where the wrong answer is chosen (valid, descriptive)
OTR-06 logit lens: residual stream after each block at the answer position, through the final
norm and unembedding; logit difference correct − other on each name's first token. Last-layer
check vs the model's own logits: Qwen3.8 0.00, Gemma 0.19 logits (bf16, final softcap 30).
Figure `f4_logit_lens.png`.

- Gemma, no instruction: for the stranded question the preference for the correct name is
  never positive at any layer; it departs from 0 at ~80% depth and goes negative. The patient
  question and "By whom was someone V-ed?" depart in the same layers, positively (final
  +29 and +14 on actives). So the wrong answer is chosen at the normal decision depth, not
  first integrated and then overridden, and not later than for other questions.
- Qwen3.8 decides all questions late (>80–90% depth); the stranded curve hovers at 0 and tips
  negative.
- Caveat: the logit lens is unreliable at mid depth; "never favours the agent" at the answer
  position does not mean the agent is absent from the representation (C3 shows it is
  available).

### C5. Shared processing sequence across 9 Instruct models (valid for Gemma and Qwen3.8; redo others)
OTR-03 (foreign-name code transplants; within-sentence regression on order / function / role)
and OTR-04 (patching the question-side state at "?" or ":"). Role code on name tokens peaks
first; the question state is strongest next ("?" 55–57% depth in Gemma and Qwen3.8); the answer
forms at the last position; the sentence period control stays ≈0. Legacy figures
`legacy_layer_role_code.png`, `legacy_layer_question_side.png`, table `legacy_layer_summary.csv`.
**Caveat:** OTR-03/04 for Qwen2.5 and OLMo-2 Instruct were measured on contaminated prompts
(forced-choice errors that are partly the C1 artefact) and must be redone. The legacy
`legacy_cross_model_otr.png` and `legacy_question_binding_depth.png` use forced-choice accuracy
and the dropped hypothesis "reading the question at '?' prevents the object-question error";
they are included for completeness only.

### C6. Stranding in general is not the cause (valid negative result; filler-gap account dropped)
SP 1.0.0: dative (to), benefactive (for) and source (from) frames; sentence forms prepositional
(po), double object (do), stranded cleft, pied-piped cleft; questions stranded ("Who did someone
give the book to?"), pied-piped ("To whom…"), agent control. Gemma: 1.00 in every cell (final
lens margins ≈ +30). Qwen3.8: 1.00 except agent questions on stranded clefts (0.90 to, 0.96 for).
Neither the alignment prediction (errors on do / stranded clefts) nor the late-cue prediction
(stranded < pied-piped) holds. Top three rows of `f5_stranded_p_frames.png`.

### C7. Passive questions in three-place frames: mostly fine, lexically and structurally conditioned errors (open)
SP 1.1.0 adds passive sentences (`pass_theme` "The book was given to Mira by Leon.", `pass_recip`
"Mira was given the book by Leon.") and passive questions (`pass_agent_stranded` "Who was the
book given to someone by?", `pass_agent_piped` "By whom…", `pass_obl_stranded` "Who was the
book given to by someone?", `pass_obl_subject` "Who was given the book by someone?"). Figure
`f5_stranded_p_frames.png` (all 108 cells), `f6_passive_agent_by_verb.png`, tables `t5`, `t6`.

- A general voice-mismatch account is **falsified**: passive questions, including passive agent
  questions, score 1.00 on active po/do sentences in to/for frames in both models; passive
  recipient questions are 1.00 almost everywhere.
- Errors cluster in **passive agent questions** only:
  - Gemma, "from" frame, active sentences: `pass_agent_stranded` 0.38 / 0.25 / 0.29 (po /
    stranded cleft / pied-piped cleft), 0.93 on the passive sentence. By verb: borrow, buy,
    learn, rent 0.00, receive 0.03 vs hide 0.98, steal 0.80, take 0.70. Also "sell" in the
    to frame 0.79 on actives overall (0.17 on stranded clefts).
  - Qwen3.8: passive agent questions on stranded clefts 0.65–0.77 (stranded), 0.33–0.73
    (pied-piped).
- In every error the wrong answer is the person "someone" stands for, as in C2.
- Working description: passive agent questions are where the error lives; its rate depends on
  verb semantics (Gemma: transfer verbs whose prepositional participant is a natural agent of
  the converse event: seller, lender, teacher, sender, landlord) and on sentence structure
  (Qwen3.8: clefts). No single rule explains C2 and C7 yet.
- Caveat: some generated passives are awkward ("Grace was gotten a coffee by Mark"); n = 60–63
  per verb in the "from" frame, 14–18 per verb elsewhere.

### C8. Question variants for the stranded "by" question (open, mixed)
Name only: ", exactly" (extra tokens after "by"): Gemma 0.59 / 0.79 (active / object cleft),
Qwen3.8 0.44 / 0.05. "Who was it that someone was V-ed by?": Gemma 0.20 / 0.69, Qwen3.8
0.56 / 0.01. The instruction line raises Gemma's bare-name accuracy on actives from 0.16
(free) to 0.63. Model-specific; not yet a clean test of any account.

## 3. Methods notes and known limits

- **Answer extraction** (`scripts/otr_generate_check.extract_answer`): direct bare name; event
  statement (transitive, passive, clefts, three-place frames) scored by the name in the asked
  role; otherwise one name left after removing quotes and copies of the sentence/question;
  else ambiguous/none (= wrong). Statements embedded in longer explanations fall through to the
  "inferred" rule. Verbatim copies of the sentence count as statements (`is_copy` flag).
- **Rescoring** (`scripts/otr_rescore_generation.py`) reproduces all generation numbers from
  stored text. Round-1 runs (16 Nov morning, 12 tokens, older row format) are skipped.
- **Greedy decoding**, bf16, transformers 5.23, one H100 per run.
- **Models so far:** Gemma 4 31B-it and Qwen3.8-27B (no thinking) for C2–C4, C6–C8; Qwen2.5
  (0.5–32B), OLMo-2 (1–32B), Glimmer 30B, Mistral Small 3.2 for C1/C5.
- **Inclusion rule for new models (proposed):** ≥0.95 on the 12 other OTR-05 wordings in every
  construction. Gemma passes; Qwen3.8 does not (by-cleft weakness on agent questions,
  0.38–0.54), so it is an interesting case rather than a clean replication.
- **Uncertainty:** no CIs in these tables yet; OTR-01 has family-level bootstrap CIs. With 164
  events per cell a proportion of 0.5 has a 95% CI of roughly ±0.08 (more with family
  clustering).

## 4. Plan and decision points

1. **Theory decision from C2 + C7:** candidate accounts to test:
   (a) the bare answer names the filler of "someone" when the question demotes the agent
   (passive agent question) and something competes for agenthood (verb semantics, focus);
   (b) copular garden path for "Who was someone…" ("who = someone") in the transitive case;
   test with "Who had someone been V-ed by?" / "Who has someone been V-ed by?", and with the
   indefinite replaced ("Who was a person V-ed by?");
   (c) converse-event confusion for transfer verbs (buy/sell, borrow/lend): test with
   matched non-transfer verbs and with the converse verb in the sentence.
2. **New families, different labs** (one model at a time; 605/4000 GiB used): OLMo 3.1 32B,
   gpt-oss-20b (reasoning on/off), Granite, Phi, Nemotron, Llama 3.x 8B; via API (no disk):
   GLM, DeepSeek or Kimi. Battery: stranded "by" + patient permutation (name only, full
   sentence), SP 1.1.0 passive agent questions, OTR-06 lens, inclusion check.
3. **Causal mechanism:** question-state curves across question tokens; probe the asked role at
   "?"; patch the "?" state from the matched question into the failing one, layer by layer,
   and test whether the bare answer is repaired.
4. **Cross-linguistic predictions** (second paper unless cheap), re-derived under whichever
   account survives step 1.
5. **Human study at the end** on frozen stimuli.
6. **Freeze and confirm:** `--test-set N` everywhere, FREEZE.md with claims, metrics and
   hashes; open test set 0 once.
