# Research communications

A programme-wide archive of approved materials used to present and explain Model Linguistics to supervisors, collaborators, conference audiences and other readers. This collection is distinct from scientific supplementary materials and does not establish additional scientific claims.

| Collection | Scope |
|:--|:--|
| [Presentations and talks](presentations/README.md) | Slides, seminars, talks and project overviews |
| [Posters](posters/README.md) | Conference and research posters |
| [Research updates](updates/README.md) | Dated progress summaries and approved meeting materials |

## Release and archival conventions

For each released item, record its title, date, audience or event (if public), version, scope, and references to the appropriate scientific sources. Keep presentation snapshots dated; don't silently replace historical versions with current findings. Only publish materials cleared for public release. Review unpublished claims, personal or internal information, permissions and submission/anonymity requirements. A draft PR in this public repository is not private storage.

The scientific evidence is maintained separately in [Paper I](../papers/learning-relations/README.md), [Paper II](../papers/order-to-role/README.md) and the [scientific supplementary-materials index](../supplementary/README.md).
