# Presentations and talks

Dated, approved slides, seminar presentations and research overviews covering one or both papers.

No presentation files have been released through this archive yet.

Store approved materials under `communications/presentations/YYYY-MM-DD-short-title/`, with a short README identifying the title, date, scope, version, audience (if public), file link and scientific sources. Preserve the distinction between an original internal version and a revised public version. Follow the [release conventions](../README.md).
