# Presentations and research updates

An index of approved presentation snapshots. Each entry describes what was communicated at the time, not necessarily the latest state of the research.

## Released presentations

No presentation files have been released through this archive yet.

Add approved files under a date-specific folder, for example:

`supplementary/presentations/YYYY-MM-DD-short-title/`

Include a short README with the title, date, event or audience (if public), paper scope, version, PDF link, and relevant scientific sources. If the presentation has been revised for public release, retain the distinction between the original internal version and the public version. Keep large or externally hosted materials linked to a stable approved release where appropriate.

Do not upload private drafts, unverified claims as definitive results, or identifying material that would compromise a blinded submission. The [research communication archive](../README.md) provides the release conventions.
