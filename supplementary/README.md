## Archival and release conventions

Each released item should have a date, title, scope (programme-wide, Paper I or Paper II), version, source/evidence references and a stable file or release link. Distinguish dated presentation claims from current scientific conclusions. Preserve earlier versions as dated snapshots instead of silently overwriting them.

Only publish materials cleared for public release. Review unpublished findings, personal or internal information, permissions and submission/anonymity requirements before uploading. Internal supervisor decks, working notes and unpublished presentation files should remain in an appropriate private workspace until cleared. A draft PR in this public repository is not a private archive.

Use the current paper names in newly prepared materials; the archive may retain original historical wording in released, dated snapshots with an explanatory note. See the [evidence policy](../docs/EVIDENCE_POLICY.md).
