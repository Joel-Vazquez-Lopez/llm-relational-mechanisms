# Research investigations

The project is organized into two scientific lines, not one undifferentiated stream of experiment numbers.

- [Scratch-trained Transformers](scratch_transformers/README.md): learning from random initialization; development, interventions, compositionality.
- [Pretrained LLMs](pretrained_llms/README.md): mechanisms in existing language models, with language and position controls.
- [Shared infrastructure](shared/README.md): provenance, tests and experiment practice.

The old `scripts/mlNNN_*.py` paths remain canonical to avoid breaking Python imports and the currently frozen ML-072 code hash. These investigation folders are real, track-specific navigation, evidence and reporting sections. They are not duplicate implementations.
