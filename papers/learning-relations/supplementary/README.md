Links point to existing, immutable Git commits instead of copying files. The index records **candidate** evidence from PR #14 without certifying scientific content, manifest integrity, reproducibility or release readiness. The PR #14 validation gates remain unchanged. Candidate material must be reviewed before final supplement selection; later manuscript versions may require a new dated link, not a silent replacement. No protected examples should be reopened. Public links are navigation, not permission to republish restricted content.

For each item retain study/version, evaluation population, endpoint and units, analysis status, uncertainty where available, and the associated paper claim. Strict four-query joint correctness (C_query), individual-answer accuracy, full-vocabulary metrics and conditional probabilities are distinct. The exact study protocol governs definitions, tie handling and aggregation. Do not promote exploratory controls or failed/gated tests to confirmed findings. Do not pool cohorts without a defensible design.

Use stable descriptive identifiers below until manuscript scope and supplement numbering are frozen. Existing historical S1/S2 labels belong to their own manuscript, not to the emerging paper.
